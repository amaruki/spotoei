# Assets

`demo.svg` is a placeholder. Replace it with a real recording or screenshot before a public
announcement, then update the image paths in the root `README.md`.

Recommended capture methods:

- **Terminal recording (GIF):**
  ```sh
  asciinema rec demo.cast
  agg --theme monokai demo.cast docs/assets/demo.gif
  ```
- **Screenshot:** capture the terminal window at roughly 100×30 cells, save as
  `docs/assets/screenshot.png`.

Keep files small (target < 5 MB for the GIF). Do not include tokens, Client IDs, account
names, or other personal data in the capture.
